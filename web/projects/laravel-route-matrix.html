What it does

A Laravel wrapper for the Google Routes API with route calculation, N×M distance matrices and waypoint optimisation. It supports five travel modes, traffic-aware routing and Eloquent integration.

The API is fluent and chainable, with helpers for the closest or fastest destination and waypoints as coordinates, Place IDs or addresses.

Highlights

  1. Driving, walking, bicycling, two-wheeler and transit travel modes.
  2. Real-time and historical traffic data.
  3. Waypoints as coordinates, Place IDs or addresses.
  4. Distance matrices across N×M origin-destination pairs.
  5. Find-closest and fastest helpers with a fluent, chainable API.
  6. 125+ Pest tests.
