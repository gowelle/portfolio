What it does

A Laravel package for moderating text and images with Google AI APIs. It ships validation rules, opt-in blocklists and an engine switch between the Natural Language API, Vision API and Gemini.

It is Swahili-first and multi-language by design: blocklists can come from files or the database, support regular expressions and are cached for repeated checks.

Highlights

  1. Text moderation for toxic, harmful or inappropriate content.
  2. Image moderation for adult, violent or racy content.
  3. Swahili-first multi-language support, extendable with custom blocklists.
  4. File- or database-backed blocklists with regex support and caching.
  5. Switch between the Natural Language API, Vision API and Gemini.
  6. Fully testable with mocked Google clients.

Install

composer require gowelle/google-moderator
