What it does

A Laravel package for analysing text and images with Azure AI Content Safety. It includes validation rules, custom blocklists, protected-material detection, multimodal analysis and strongly typed results.

Batch and asynchronous analysis are supported, and failures are retried. The package is covered by 90+ tests, integration tests against the real Azure API, and PHPStan level 6.

Highlights

  1. Text and image moderation with configurable severity thresholds.
  2. Multimodal analysis: text and image together (preview).
  3. Custom blocklist management and protected-material detection.
  4. Strongly typed DTO results and Laravel validation rules.
  5. Retry handling plus artisan commands for testing and management.
  6. 90+ tests, integration tests and PHPStan level 6.
