About

A short version: I am John, and I would rather build the missing tool than work around it.

I'm John Gowelle, a software developer in Tanzania working in PHP, Laravel and Swift. I build the tools I wish existed, then share them — and they work on my machine.

Each package here exists because I needed it in a real project and didn't like what I found: a payment API that deserved a better wrapper, a moderator that needed to speak Swahili first, a Mac that refused to be left behind.

What I believe about software

  1. It should work the moment you install it.Every set-up step is a place to lose someone.
  2. Tools for getting started should be free.Nobody should pay for the ground they stand on.
  3. Software shouldn't ask what it can find out.If the answer is on the machine, go and look.
  4. “Works on my machine” is where testing starts.It is not where it ends. I have checked.
